## YYYY-MM-DD - RatingStars Keyboard Accessibility\n**Learning:** Interactive star rating components often use `div` elements and mouse events, lacking native keyboard support. By giving the container a `role="slider"` and handling Arrow keys (Left/Right) and Home/End keys, we can make the component accessible for keyboard users without needing to make every individual star focusable, saving tab stops while providing a familiar interaction model.\n**Action:** Apply `role="slider"`, manage `aria-valuenow`, and handle `ArrowUp`/`ArrowDown`/`ArrowLeft`/`ArrowRight` keys for custom rating components.
