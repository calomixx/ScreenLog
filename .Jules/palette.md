## 2024-05-08 - MediaCard Accessibility Enhancement\n**Learning:** The `MediaCard` component wrapper serves as an interactive element but lacks native interactive semantics. When adding `onKeyDown` support to complex custom interactive elements with nested buttons, event bubbling from children must be prevented (`e.target !== e.currentTarget`) to avoid overriding child actions.\n**Action:** Always verify keyboard focus states and implement keydown event bubbling guards for custom interactive wrapper components containing nested action buttons.
