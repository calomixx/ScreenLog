## 2024-11-04 - Improve MediaCard keyboard accessibility\n**Learning:** The MediaCard component in the app acts as an interactive list item/button (opens modal) but uses a `div` without keyboard accessibility properties (`tabIndex`, `onKeyDown`, `role`, `aria-label`). Adding `onKeyDown` with a target check is critical to avoid intercepting nested button clicks.\n**Action:** Add `tabIndex={0}`, `role="button"`, `aria-label`, and `onKeyDown` to interactive card containers while preventing event bubbling issues.
