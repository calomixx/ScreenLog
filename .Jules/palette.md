## 2026-10-30 - Interactive Card Keyboard Accessibility\n**Learning:** When making wrapper elements like custom cards interactive with `onKeyDown` for keyboard users, native child buttons within the card can unintentionally bubble up their 'Enter'/'Space' events and trigger the wrapper's action.\n**Action:** Always include an event bubbling guard (`if (e.target !== e.currentTarget) return;`) in the wrapper's `onKeyDown` handler to prevent breaking nested interactions.
