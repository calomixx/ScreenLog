## $(date +%Y-%m-%d) - MediaCard Keyboard Accessibility
**Learning:** Custom interactive elements (like `MediaCard` components) used for primary actions lack native keyboard interaction and focus states.
**Action:** Ensure custom interactive elements implement keyboard accessibility using `role="button"`, `tabIndex={0}`, `onKeyDown` handlers (for 'Enter' and 'Space'), and clear `:focus-visible` styles, along with explicit `aria-label`s for internal icon-only actions. Note: Adding `role="button"` to a container that has nested buttons is technically an ARIA anti-pattern. While this improves baseline keyboard navigation, a better pattern would be keeping the card container semantic (e.g., `<article>`) and using a visually hidden link/button or the "block link" CSS technique for the primary action.
